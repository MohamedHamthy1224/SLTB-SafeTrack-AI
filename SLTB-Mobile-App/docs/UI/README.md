# UI / UX Documentation

This directory contains all user interface and user experience documentation.

## Purpose

Document the design system, screen flows, wireframes, and UI specifications for the mobile application.

## Structure

```
UI/
├── Images/          # UI screenshots, design exports
├── wireframes/      # Low-fidelity wireframes
├── mockups/         # High-fidelity mockups (Figma exports)
└── design-system.md # Design system documentation
```

## Planned Documents

| File | Description |
|------|-------------|
| `design-system.md` | Colors, typography, spacing, component specs |
| `screen-flows.md` | Navigation flow diagrams |
| `component-library.md` | UI component specifications |
| `accessibility.md` | Accessibility guidelines and requirements |
| `Images/` | Exported screen screenshots |

## Design Tools

- **Figma** — Primary UI design and prototyping tool
- **Zeplin** — Design-to-developer handoff
- **InVision** — Interactive prototype sharing
