# UI Images Directory

This directory stores UI screenshots, design exports, and visual documentation assets.

## Purpose

- Store exported screen designs from Figma
- Store annotated screenshots for documentation
- Store before/after comparison images for change tracking

## Naming Convention

```
{screen-name}_{version}_{state}.png

Examples:
  login_v1.0_default.png
  dashboard_v1.0_loaded.png
  alerts_v1.0_empty-state.png
  alert-details_v1.2_critical.png
```
