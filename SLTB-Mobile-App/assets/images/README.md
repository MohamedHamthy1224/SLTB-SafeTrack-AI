# Assets — Images

This directory contains all image assets for the SLTB Mobile App.

## Content Types
- App logo
- Background images
- Onboarding illustrations
- In-app imagery

## Naming Convention
```
{context}_{description}_{variant}.{ext}
Examples:
  logo_sltb_dark.png
  bg_login_dark.jpg
  img_empty_state_alerts.png
```

## Supported Formats
- PNG (preferred for logos, icons, illustrations)
- JPG (photos, complex backgrounds)
- WebP (optimized web images)

## Required Sizes
- @1x (mdpi baseline)
- @2x (xhdpi)
- @3x (xxhdpi — iOS Retina)
