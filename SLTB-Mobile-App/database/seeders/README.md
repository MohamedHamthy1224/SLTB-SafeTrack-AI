# Database Seeders Directory

This directory contains database seed data scripts.

## Purpose

Populate the database with initial or test data for development,
staging, and production environments.

## Seeder Categories

### Development Seeds (dev only)
- Test officer accounts with known credentials
- Sample alert datasets

### Production Seeds (safe for production)
- Initial admin officer account
- System configuration data
- Alert type reference data
