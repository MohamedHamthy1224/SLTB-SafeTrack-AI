# Meeting Notes

This directory stores all project meeting notes, sprint retrospectives, and team decisions.

## Purpose

Maintain a chronological record of all project meetings, design decisions, and action items.

## File Naming Convention

```
YYYY-MM-DD_{meeting-type}_{brief-description}.md

Examples:
  2024-08-01_kickoff_project-foundation-review.md
  2024-08-15_sprint-planning_phase-2-authentication.md
  2024-09-01_retrospective_sprint-2-review.md
  2024-09-05_design-review_dashboard-ux-feedback.md
```

## Meeting Types

| Type | Description |
|------|-------------|
| `kickoff` | Project kickoff meetings |
| `sprint-planning` | Sprint planning sessions |
| `retrospective` | Sprint retrospective reviews |
| `design-review` | UI/UX design review meetings |
| `technical-review` | Technical architecture reviews |
| `stakeholder` | Stakeholder update meetings |
| `ad-hoc` | Unscheduled meetings |

## Meeting Note Template

Use the following template for all meeting notes:

```markdown
# Meeting: {Title}
**Date:** YYYY-MM-DD
**Time:** HH:MM — HH:MM
**Attendees:** Name1, Name2, ...
**Facilitator:** Name

## Agenda
1. Item 1
2. Item 2

## Discussion Points
...

## Decisions Made
- Decision 1
- Decision 2

## Action Items
| Action | Owner | Due Date |
|--------|-------|---------|
| Task | Person | YYYY-MM-DD |

## Next Meeting
**Date:** YYYY-MM-DD
```
